## 🏛️ Creative Direction & Visual Philosophy

- **Hybrid Direction**: Editorial Luxury × Experimental Digital Experience.
- **Editorial Color Palette**:
  - **Obsidian**: `#090B0F` (Base background)
  - **Warm Ivory**: `#F2F1EC` (Primary typography & light surfaces)
  - **Muted Slate**: `#89919D` (Secondary structure & metadata)
  - **Ice Blue**: `#A9DDF0` (Restrained interactive focal point)
- **Interaction & Motion Craft**:
  - **Lenis Smooth Inertia**: Organic vertical scroll pacing.
  - **Framer Motion Springs**: Calibrated stiffness and damping physics.
  - **Web Audio API**: Synthesized harmonic micro-chimes (pentatonic scale) with instant global mute toggle.
  - **Tactile Magnetic Cursor**: Subtle cursor follower with contextual state feedback (disabled on touch devices and when `prefers-reduced-motion` is active).

## 🗂️ Featured Product Showcase

1. **MEDesy Solution** *(Telehealth & Conversational UX — Current Employment)*
   - WhatsApp-first healthcare platform connecting patients to licensed Nigerian doctors, conducting structured symptom triage without app installation barriers.
2. **9jaTrip** *(Urban Mobility & Transit — Freelance)*
   - Pragmatic multi-modal commuter transit app unifying cabs, keke napep, and okada with transparent fare estimation, digital boarding receipts, and driver verification.
3. **Somewhere Hotel** *(Hospitality & Spatial Web — Concept)*
   - Cinematic coastal sanctuary web experience with real-time daylight atmosphere controls (Sunset Suite, Arrival Facade, Twilight Penthouse) and reservation demonstration.
4. **BuyBuddy** *(Social Micro-Commerce — Personal Product MVP)*
   - Lightweight micro-retail studio empowering social vendors to publish instant product catalogs and receive 1-tap structured order summaries directly in WhatsApp.
5. **Stillwater Hall** *(Performing Arts & Interactive Ticketing — Concept)*
   - Spatial concert venue scrollytelling journey guiding attendees from night exterior blue hour to acoustic center stage and interactive tier seat selection.

## 🛠️ Tech Stack & Architecture

- **Framework**: [Next.js 16 (Turbopack App Router)](https://nextjs.org/)
- **UI & State**: React 19, TypeScript
- **Styling**: Tailwind CSS v4, CSS Custom Variables
- **Motion & Physics**: Motion (`motion/react` / Framer Motion), GSAP
- **Scroll & Inertia**: Lenis
- **Sound**: Web Audio API Synthesizer (custom lightweight sound engine in `@/lib/sounds.ts`)

## 🚀 Getting Started Locally

### Prerequisites
- Node.js 18.18+ (tested on Node.js 20 & 24)
- npm, pnpm, or yarn

### 1. Clone the repository
```bash
git clone https://github.com/Bheemty/cold-designer-portfolio.git
cd cold-designer-portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 4. Build for production
```bash
npm run build
npm run start
```
All routes pre-render statically with zero required environment variables.
